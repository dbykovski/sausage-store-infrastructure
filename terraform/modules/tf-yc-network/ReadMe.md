Этот модуль Terraform предназначен для работы с сетевыми ресурсами Yandex.Cloud. Он позволяет:

Получать информацию о существующей VPC сети по умолчанию

Получать данные о подсетях в указанных зонах доступности

Проверять корректность выбранной зоны доступности для создания инстансов

Зависимости модуля
Terraform версии 1.5.7 или выше

Провайдер Yandex.Cloud версии 0.87.0 или выше

Настраиваемые параметры
instance_zone
Описание: Зона доступности для создания инстанса

Тип: string

Значение по умолчанию: "ru-central1-a"

Допустимые значения:

ru-central1-a

ru-central1-b

ru-central1-c

Валидация: Автоматически проверяется, что указана корректная зона

Обязательность: Обязательный параметр (nullable = false)

Выходные данные (outputs)
yandex_vpc_subnets
Описание: Карта подсетей Yandex.Cloud

Тип: Map объектов подсетей

Содержимое: Информация обо всех запрошенных подсетях (по зонам доступности)
